# dwm

基于 [dwm](https://dwm.suckless.org) 6.5 的定制构建（补丁、dwmblocks、slock）。

## 文档

| 语言 | 文件 |
|------|------|
| 简体中文 | [docs/zh-CN.md](docs/zh-CN.md) |
| English | [docs/en.md](docs/en.md) |

## 快速开始

```bash
cd dwm && make && sudo make install
cd dwmblocks && make && sudo make install
```

快捷键、布局、状态栏与脚本说明见 [docs/zh-CN.md](docs/zh-CN.md) 或 [docs/en.md](docs/en.md)。
